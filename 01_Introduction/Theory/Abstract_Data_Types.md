# Abstract Data Types

Often, we want to talk about data structures without worrying about
implementation details associated with particular programming
languages or how data is stored in computer memory.

## Abstract Mathematical Models

Abstract mathematical models can be used to describe particular
classes of data structures or data types that have common features.

These are called **Abstract Data Types (ADTs)**.

## Definition

Abstract Data Types are defined only by the operations that may be
performed on them.

Typically, we specify:

- How they are built out of more primitive data types
- How to extract data from them
- Basic checks to control the flow of processing in algorithms

Examples of primitive data types mentioned in the notes include:

- Integers
- Strings

## Encapsulation

The idea that implementation details are hidden from the user and
protected from outside access is known as **encapsulation**.

The notes will provide many examples of abstract data types.
