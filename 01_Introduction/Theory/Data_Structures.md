# Data Structures

For many problems, the ability to formulate an efficient algorithm
depends on being able to organize the data in an appropriate manner.

## Definition

A **data structure** is a particular way of organizing data for
particular types of operation.

## Data Structures Covered

These notes look at numerous data structures, ranging from familiar
structures to more complex structures.

### Familiar Data Structures

- Arrays
- Lists

### More Complex Data Structures

- Trees
- Heaps
- Graphs

## Importance of Data Structures

The choice of a data structure affects the efficiency of the algorithms
based upon it.

The notes study how different data structures can be used with
algorithms for different tasks.
